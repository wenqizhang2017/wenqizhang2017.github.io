# Wenqi Zhang - Personal Website

Source code for [wenqizhang2017.github.io](https://wenqizhang2017.github.io/).

The site is built with Hugo and Hugo Blox. Changes pushed to `main` are built and deployed automatically with GitHub Actions.

## Local development

Install the Hugo Extended version specified in `.github/workflows/publish.yaml`, then run:

```sh
hugo server
```

Site content is stored under `content/`, configuration under `config/_default/`, and custom presentation overrides under `assets/css/` and `layouts/`.
